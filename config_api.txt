# ── Image Options ─────────────────────────────────────────────────────────────
# TEITOK bboxes are page-image pixels with the origin at the page's top-left corner —
# the convention of the TEITOK tools themselves (flexiconv, teitok-tools).
# INPUT_PAGES_DIR: per-page images named <doc_id>-<N>.<png|jpg|tif>; when present, bboxes
#   are scaled to the image size (sx = image width / ALTO Page WIDTH, or / PrintSpace WIDTH
#   under BBOX_ORIGIN=printspace).
# IMAGE_DPI / ALTO_DPI: with no image, derive the scale from the ALTO MeasurementUnit
#   (inch1200, mm10) or from ALTO_DPI for pixel units. Empty = no scaling.
# BBOX_ORIGIN: "page" (default) keeps ALTO page coordinates; "printspace" subtracts the ALTO
#   PrintSpace origin and declares a PrintSpace-sized <surface> — only for page images that
#   were cropped to the print space. Written as ${BBOX_ORIGIN:-page} so it can be set for one
#   run (`BBOX_ORIGIN=printspace bash api_4_stats.sh`) without editing this file.
INPUT_PAGES_DIR=""
IMAGE_DPI=""
ALTO_DPI=""
BBOX_ORIGIN="${BBOX_ORIGIN:-page}"
