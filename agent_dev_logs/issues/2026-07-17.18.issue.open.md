### Recommendation: **INCEpTION** (fallback: **doccano**)

It maps 1:1 onto the workflow already designed in #7 and makes the correction step genuinely *faster* than the previously-assumed BRAT:
1. **Speed** — external-recommender API plugs in our existing constrained-decoding LLM stack (`llm_run.py`/`llm_utils.py`) and/or a bootstrapped NameTag/spaCy model that **active-learns as annotators work** (accept suggestions with a keystroke).
2. **Gold set** — multi-annotator curation/adjudication + inter-annotator agreement.
3. **Future-proof** — native nested/overlapping spans preserve `bronze = B-MATERIAL|B-ARTEFACT` for the deferred seq2seq v2, no re-annotation.
4. **Token-aligned** — import the UDPipe CoNLL-U so exported spans align exactly to NameTag's tokens.
5. Maintained + Docker (BRAT is Python-2, unmaintained since 2012 → not a safe 2026 container).

**Trade-off:** INCEpTION is the heaviest option and ships MariaDB + its own login — the project's first stateful/auth service. For a **standalone campaign** deploy it's self-contained in one `docker-compose`; the persistence/auth deviation from the no-DB/no-auth convention should be flagged to @rharasim before any shared hosting. If minimum setup + flat-v1-only is preferred, **doccano**'s JSONL import fits the LLM pre-annotations directly.

### Deployment (chosen: standalone campaign)

Own `docker-compose` on a UFAL/ARÚP host, used only for the campaign. Schema config + converters live in `atrium-nlp-enrich`; nothing is added to the runtime pipeline — the only contract with the pipeline is the exported IOB2 files.

### Common setup (tool-agnostic)

1. Freeze the `archaeo` scheme (6 types + boundary guidelines from #7) as `annotation/archaeo_tagset.json` + `GUIDELINES.md` (doubles as annotator handout).
2. `data_samples` CSV → token-segmented CoNLL-U via existing `api_util/call_udpipe.py`.
3. LLM pre-annotations via existing `llm_run.py::build_schema()/build_system_prompt()` + `llm_utils.py`.
4. Two small converters: `preannot_to_<tool>` (in) and `export_to_iob2` (out → two tab cols, `-DOCSTART-→O`, blank-line sentence breaks, `|`-joined overlaps; validate with NameTag's `preprocessing/iob_to_iob2.py`). The pipeline is already pipe-aware via `call_nametag.py::_get_ne_suffix()`.
5. Add archaeo entries to `api_util/summarize_nt_udp.py` tag maps (TEITOK interop: `LOCATION→LOC`, rest→`MISC`).

### INCEpTION usage flow

deploy (`inception` + `mariadb`) → create project, NE layer set to *"Any (stacked and overlapping)"* with the 6-value tagset → import CoNLL-U → wire external recommender (LLM/NameTag) + active learning (or batch-import predictions to start) → annotators correct → curate to gold + read IAA → export CoNLL → convert to IOB2 → into #7 training.

### Verification (tiny sample first)

Stand up tool → one Czech doc through UDPipe → LLM pre-annot → import → hand-correct ~10 sentences covering all 6 types incl. one overlap → export → convert → validate IOB2 (round-trips through `iob_to_iob2.py`, parses via `_get_ne_suffix()`) → NameTag training dry-run + `TAGSETS` registration → time annotators with vs. without recommenders to confirm the "fast" claim.
