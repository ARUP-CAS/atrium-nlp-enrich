# Strategy — Issue #6: TEATER keyword extraction via local LLM

> Issue [#6](https://github.com/ufal/atrium-nlp-enrich/issues/6) · Labels: `enhancement`, `development`, `a big one` · **Status: ✍️ In progress**

## Context
The local-LLM semantic-enrichment pipeline is **built and benchmarked**: `llm_run.py` →
`llm_pipeline.py` → `llm_utils.py`, driven by `llm_config.txt`, vocabulary via `vocab_manager.py`,
on a **vLLM** backend with **constrained JSON decoding** (`guided_decoding_backend="xgrammar"`)
and **automatic prefix caching** (the full-vocabulary system prompt computed once, KV-cache
reused per line). A 13-model bake-off (8–70B) settled the defaults. What keeps #6 `In progress`
is the standing TODO to evaluate **larger models** — blocked until the cluster GPU drivers were
updated for vLLM ≥0.8 (drivers since updated, 2026-06-23; the bigger-model run is the next step).

This plan covers the constrained-decoding strategy, the structured-prompt contract, and the
remaining model-evaluation work.

## Strategic actions

### A — Run the deferred large-model evaluation (the open TODO)
1. With drivers updated, run the staged registry entries (`qwen3-235b-a22b`(-fp8),
   `deepseek-v3`, `llama4-maverick`, `llama3.1-70b`) on the same fixed sample used for the
   8–70B bake-off, so scores are comparable.
2. Score against the **same three litmus tests** that predicted failure: form-labels-as-content
   ("Druh nálezu"), ambiguous abbreviations ("Kultura Z." → correct answer is *uncertainty*),
   and location headers (sliding-window bleed). These are the cheap, high-signal probes.
3. Decide whether any large MoE beats Qwen 3.6-27B enough to justify the VRAM; if not, the 27B
   default stands and this closes #6.

### B — Lock the structured-prompt + schema contract
- Keep the **`Nerelevantní (meta-text)`** category injected at index 0 and guaranteed to
  survive context-window truncation (the fix that killed the country-default and form-label
  hallucinations on weak models).
- Keep **temperature 0** and the most-specific-term preference (`zlomek keramiky` > `keramika`)
  encoded in the system prompt; document these as the contract so a model swap can't silently
  drop them.
- Prefer **specificity + conservatism** as the selection criterion, not raw confidence — the
  bake-off showed misleadingly-high 1.0 confidences on the worst over-generalisers (Mistral
  Nemo's `hradiště` bias, Bielik/Llama country defaults).

### C — Deployment tiers (record, don't re-derive)
- **Production default:** Qwen 3.6-27B (single A100/A40, no bleed/hallucination).
- **Max precision:** Gemma 4-31B (~21 GB VRAM + gated HF token) for burial/find-type work.
- **CPU / low-VRAM:** Qwen 3.5-9B (only sub-14B model with zero context bleed on the sample).
- **Deprecate:** Qwen 2.5-14B AWQ and the archived 7–8B set (below the reliability threshold).
