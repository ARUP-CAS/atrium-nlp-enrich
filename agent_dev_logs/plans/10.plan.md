# Strategy — Issue #10: Flexiconv-supported input formats

> Issue [#10](https://github.com/ufal/atrium-nlp-enrich/issues/10) · Labels: `enhancement`, `development`, `a big one` · **Status: 🔍 Tocheck — implemented + test-covered; real-practice conversion run pending (issue open)**

## Context
The pipeline can now ingest **any Flexiconv-supported non-tabular format** (pdf, docx, odt, rtf,
html, md, txt, epub, tei, conllu, …) by converting it **directly to TEITOK XML** — bypassing
UDPipe/NameTag — while keyword extraction and LLM enrichment were extended to **discover and
read** those `.teitok.xml` files via a shared, **stdlib-only** reader. CSV/XLSX keep stages 1–4
unchanged; Flexiconv is an **optional, lazily-imported** dependency. 

The implementation landed initially in `efbf8b8`; `5f34f982` ("add tests and fixtures for issue #10")
resolved the test-coverage gap. The dependency is strictly pinned and spatial coordinate alignments
for PAGE XML/hOCR are established in the test suite. **Caveat (K4TEL, 2026-06-28): the flexiconv
conversion itself has not been tested in practice yet — the issue stays open until real
conversion experiments are conducted.**

## B — Validation specifics
### A — Format + data validation
1. **Text conservation:** `<s text="...">` matches the raw text, and `<tok>` reconstruction
   matches exactly (honouring `join=right` / `spaceAfter=No`).
2. **NER wrappers:** `NER=B-P|I-P` in CoNLL-U correctly wraps tokens in `<name type="PER">`.
3. **Coordinate logic:** `api_4_stats.sh` scaling aligns PAGE XML and hOCR bboxes without regressions.

### B — Integration
4. **Keywords:** run `keywords.py -i $OUTPUT_DIR/TEITOK -m yake`. (Note: legacy KER backend
   will produce poor/empty results without base lemmas on layout-free docs
   (no POS), **yake/keybert** work regardless.)
5. LLM: set `INPUT_DIR=$OUTPUT_DIR/TEITOK`, run `llm_run.py` → `<doc>_enriched.json`;
   `doc_id_from_path` successfully strips the double `.teitok.xml` suffix.
6. Synthesized `categ=""` rows are treated as normal text by `_should_process_line`
   (only `min_char_count` gates them) and missing `quality_score` defaults to 0.0 safely.

### C — Regression + UX guards
7. **Tabular regression:** rerun `api_1..4` on a CSV/XLSX `INPUT_TABLES_DIR` → byte-identical
   outputs.
8. **Missing-dep UX:** a `.docx` in `INPUT_DOCS_DIR` **without** Flexiconv installed → clear
   install hint to stderr + paradata `skip`, file skipped, run continues, readers/tabular unaffected.
9. `pytest` passes **without** Flexiconv (readers are stdlib; conversion tests mock the
   lib + `subprocess`/`shutil.which`).
