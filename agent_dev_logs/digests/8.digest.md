## 🎯 Goal
A **single-file API entry point** that takes ordered text lines (CSV column, txt, or anything
with ordered text lines) and runs the whole pipeline to **NLP-enriched `teitok.xml`** + keywords
+ LLM JSON — wrapping the existing shell stages (`manifest` → `udp` → `nt` → `stats`) behind
HTTP. Merged driver: `run_pipeline.py` (commit `3928c67`).

## 🧩 API surface (`service/api.py`)
- **`/enrich`** — synchronous; runs the full pipeline, returns TEITOK envelope (or `format=zip`).
- **`/enrich_text`** — text-in convenience variant (`{"lines": [...]}`).
- **`/jobs`** — background task queue with a semaphore cap + lazy TTL eviction of old jobs.
- **`/rescale`** (added `d952301`, #9) — single-page `teitok.xml` + image width/height → XML with
  bboxes scaled to the image (pure coordinate transform; also standalone `fix_teitok_bboxes.py`).
  Includes the `</n> → </name>` repair (default on, `fix_names=false` to disable).
- **`/health`** — config validity via `run_pipeline.py --dry-run`; **`?deep=true`** additionally
  HEAD-probes the UDPipe/NameTag LINDAT URLs.
- **`/info`** — stage plan, pinned UDPipe/NameTag models, kw methods + default, limits.
