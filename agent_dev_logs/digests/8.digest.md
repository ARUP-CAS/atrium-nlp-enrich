## 🎯 Goal
A **single-file API entry point** that takes ordered text lines (CSV column, txt, or anything
with ordered text lines) and runs the whole pipeline to **NLP-enriched `teitok.xml`** + keywords
+ LLM JSON — wrapping the existing shell stages (`manifest` → `udp` → `nt` → `stats`) behind
HTTP. Merged driver: `run_pipeline.py` (commit `3928c67`).

## 🧩 API surface (`service/api.py`)
- **`/enrich`** — synchronous; runs the full pipeline, returns TEITOK (or `zip`).
- **`/enrich_text`** — text-in convenience variant.
- **`/jobs`** — background task queue with a semaphore to cap concurrent runs.
- **`/rescale`** (added `d952301`) — takes a single-page `teitok.xml` + image width/height,
  returns the XML with bounding boxes scaled to the image (pure XML coordinate transform; also
  available standalone as `fix_teitok_bboxes.py`). Includes a `</n> → </name>` fix in the
  returned TEITOK.
- **`/health`** — config validity via `run_pipeline.py --dry-run` (LINDAT reachability probe
  spec'd but not implemented — documented partial).
- **`/info`** — stage plan, pinned UDPipe/NameTag models, kw methods + default, limits.
