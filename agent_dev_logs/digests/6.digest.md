## 🎯 Goal
Map OCR lines onto a user-defined "vocabulary" (the TEATER topic taxonomy) via an LLM request, emitting structured keywords + confidences with paradata. Pipeline: `llm_run.py` (entry point) → `llm_pipeline.py` → `llm_utils.py` (shared), driven by `llm_config.txt`; vocabulary handled by `vocab_manager.py`.

## 🏆 Model bake-off (final, commit `733f8e4`, 8–70B)

| Model | Score | Verdict |
|---|---:|---|
| **Gemma 4-31B** | 100% | 🥇 Best — never bleeds context across lines, conservative on ambiguous abbreviations, always picks the most specific TEATER term (`zlomek keramiky` > `keramika`, `pohřeb kostrový` > `hrob`); 1.0 confidence only on genuine meta-text. Cost: ~21 GB VRAM + gated HF token. |
| **Qwen 3.6-27B** | 94% | ✅ correct **default** — one deduction (`sklep` where `jáma zásobní` fits the krechty context); resists guessing culture from the ambiguous `Kultura Z.` abbreviation. |
| **Qwen 3.5-9B** | 81% | Punches above its class; zero context bleed, conservative; slightly imprecise on burial / storage-pit. Strong **CPU / low-VRAM** candidate. |
| **Qwen 3-14B** | 75% | Solid but context-bleed on `CTX199405706` (header L3 + intro L26 classified with vocabulary from the *next* content line). |
| **Qwen 2.5-14B AWQ** | 62% | Worst hallucination in the set (assigns `kultovní/sakrální objekt` @0.75 to a plain intro sentence with no basis); misassigns `jáma zásobní`. Deprecate. |

Earlier rounds also evaluated Qwen 2.5-7B, Mistral Nemo 12B, Bielik 11B, Llama 3.1-8B. The dominant failure mode on weak models is **repetitive looping** plus meta-text leaking into keywords.

## 🔧 Implementation
**vLLM backend** (commit `3e24876`) — `load_vllm_engine()` in `llm_utils.py`:
- `tensor_parallel_size` — auto-shards across N GPUs, no manual pipeline cuts.
- `enable_prefix_caching=True` — Automatic Prefix Caching: the system prompt (which embeds the **full vocabulary**) is computed once and its KV-cache reused for every line in every document → the primary throughput multiplier here.
- `guided_decoding_backend="xgrammar"` — native constrained JSON decoding (no `lm-format-enforcer`).

**Bug fixes** (Issue #6 items 7 & 8, commit `3e24876`):
- **#7 — silent abort with no marker.** On 10 consecutive errors the loop broke silently. New `_write_abort_marker()` writes a sidecar `<stem>_enriched.abort.json` (abort reason, lines processed, error count, UTC timestamp) regardless of partial results; `stats["aborted"]` added for programmatic checks.
- **#8 — empty `categ` passes unguarded.** In `_should_process_line` an empty string fell through every category guard. Explicit `if not categ:` branch now handles it with a labelled `[unknown categ]` skip.

Config / registry: new model entries and archived/deprecated models tracked in `llm_config.txt`; `vocab_manager.py` updates.
