## 🎯 Goal
Train a domain-specific (archaeological) NER model on the NameTag 3 framework for the ATRIUM enrichment stage, validated and corrected with Opus 4.8.

## 🔑 Decisions locked

| # | Decision | Rationale |
|---|----------|-----------|
| 1 | **Flat tagset v1** (6 types); record overlaps as pipe-tags in the data for a possible nested v2 | NameTag 3 multitagset is currently flat-only, and most NameTag models are flat. Nothing lost by keeping nested spans in the data now and deferring a seq2seq v2. |
| 2 | **Phase 0 pilot on existing public data first** (Brandsen, Dutch) | Learn the full NameTag 3 training/eval loop at ~zero annotation cost before spending on Czech. |
| 3 | **One multitagset model**: Czech CNEC 2.0 + new `archaeo` tagset | Single XLM-R network served under multiple aliases; fits the single-endpoint pipeline; no label collisions. |
| 4 | **Base = `nametag3-multilingual-260521`** (355M XLM-RoBERTa); reuse ArchaeoBERT **guidelines**, not weights | ArchaeoBERT is English/Dutch BERT — wrong language & backbone. XLM-R covers Czech now and Dutch/English for later expansion. |

## 🏷️ `archaeo` tagset (flat, IOB2)
```python
"archaeo": [
    "O",
    "B-ARTEFACT", "I-ARTEFACT",
    "B-PERIOD",   "I-PERIOD",
    "B-LOCATION", "I-LOCATION",
    "B-CONTEXT",  "I-CONTEXT",
    "B-MATERIAL", "I-MATERIAL",
    "B-SPECIES",  "I-SPECIES",
]
```
- **Separate** tagset — *not* remapped into CNEC two-letter codes (those collide / don't exist).
- Nested overlaps live in the **data**, e.g. `bronze → B-MATERIAL|B-ARTEFACT` (usable by a future seq2seq v2; the flat v1 head takes the first/most-specific tag).
- Coarse interop for TEITOK `@type`: `LOCATION → LOC`; the rest → `MISC` (or add archaeo coarse types if archaeo-specific TEITOK querying is wanted).

## 📚 Why ArchaeoBERT is reference-only
ArchaeoBERT = `bert-base-cased` continually pre-trained on ~44,000 documents / 264M tokens from the Archaeology Data Service (ADS), casing retained because capitalization delineates semantic boundaries (`Early Bronze Age` vs `early artifacts`). Useful as **annotation guidelines**, but English/Dutch BERT is the wrong backbone for Czech — hence the XLM-R base in decision #4.

## 🗺️ Roadmap / open TODOs
- **Phase 0:** run the NameTag 3 train/eval loop end-to-end on Brandsen Dutch data.
- Build the Czech `archaeo` training data; LLM-assisted pre-annotation prompt drafted.
- Serve CNEC 2.0 + `archaeo` from one multitagset endpoint.
- Defer nested-span seq2seq v2 until v1 is validated.
