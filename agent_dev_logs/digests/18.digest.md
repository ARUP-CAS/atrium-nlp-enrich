## 🎯 Goal
Pick (or build) a **fast** annotation tool to label texts with the six new `archaeo` NE types, producing human-corrected **IOB2** training data for the domain-specific NameTag 3 model. Prior planning docs had defaulted to BRAT without a comparison; #18 is the explicit "pick one / suggest open-source alternatives" task.

## 🔑 Decision (Pending)
Evaluated four open-source candidates against the #7 workflow (**LLM pre-annotate → human correction → export IOB2**), Czech-first text, multiple archaeologist annotators, and the project's no-DB/no-auth convention. **No final tool is locked yet; all options remain possible pending stakeholder consultation.**

| Criterion                           | Label Studio (testing) | doccano          | INCEpTION                      | BRAT                          |
|-------------------------------------|------------------------|------------------|--------------------------------|-------------------------------|
| Maintained (2026)                   | Yes                    | Yes              | Yes                            | **No — v1.3, 2012; Python 2** |
| Model-in-the-loop / active learning | Yes (ML backend)       | No (import only) | **Yes** (external recommender) | No                            |
| Pre-annotation import               | JSON preds             | **Clean JSONL**  | CoNLL/CAS/recommender          | write `.ann`                  |
| Nested / overlapping                | Yes                    | Weak toggle      | Yes                            | Yes (native)                  |
| Curation + IAA                      | Multi-user             | Thin             | **Yes**                        | No                            |
| Setup / stateful footprint          | Medium (PG)            | **Lightest**     | Heaviest (MariaDB + auth)      | Python-2 pain                 |

- **Label Studio**: Currently under active testing; easy setup and natively handles LLM pre-annotations.
- **doccano**: The lightest to stand up; keyboard-driven flat NER. 
- **INCEpTION**: If model-in-the-loop active learning + multi-annotator curation/IAA + native nested spans become worth the heavier setup (adds a DB + auth → first stateful service; flag to `rharasim`).
- Dismissed: **Vi(M)** (single-user, no validation/IAA/token-aligned export), **Prodigy** (commercial), and **BRAT** (unmaintained/Python 2).

## 🏷️ `archaeo` types + output format
Six flat types `ARTEFACT · PERIOD · LOCATION · CONTEXT · MATERIAL · SPECIES` (hotkeys a/p/l/c/m/s). Export target = NameTag 3 IOB2: UTF-8, two tab-separated columns `token⇥label`, blank line between sentences, `-DOCSTART-→O`, `|`-joined labels for overlaps (`bronze → B-MATERIAL|B-ARTEFACT`) — the format `api_util/call_nametag.py::_get_ne_suffix` already parses.

## 📦 What landed (`annotation/`)
- `docker-compose.yml` + `.env.example` — Standalone deployments prepared.
- `archaeo_labels` — 6-type label set definitions.
- `GUIDELINES.md` — per-type boundary rules (from #7 / ArchaeoBERT).
- Data Converters — CoNLL-U **or** IOB2 TSV to standard JSON schema, and exporter scripts to convert back to NameTag IOB2.
- `api_util/summarize_nt_udp.py` — Updated to map archaeo types for downstream TEITOK display (`LOCATION→LOC`, rest→`MISC`).
