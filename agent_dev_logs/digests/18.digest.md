## 🎯 Goal
Pick (or build) a **fast** annotation tool to label texts with the six new `archaeo` NE types, producing human-corrected **IOB2** training data for the domain-specific NameTag 3 model. Prior planning docs had defaulted to BRAT without a comparison; #18 is the explicit "pick one / suggest open-source alternatives" task.

## 🔑 Decision
Evaluated four open-source candidates against the #7 workflow (**LLM pre-annotate → human correction → export IOB2**), Czech-first text, multiple archaeologist annotators, and the project's no-DB/no-auth convention.

| Criterion | doccano ⭐ (chosen) | INCEpTION (fallback) | Label Studio | BRAT |
|---|---|---|---|---|
| Maintained (2026) | Yes | Yes | Yes | **No — v1.3, 2012; Python 2** |
| Model-in-the-loop / active learning | No (import only) | **Yes** (external recommender) | Yes (ML backend) | No |
| Pre-annotation import | **Clean JSONL** | CoNLL/CAS/recommender | JSON preds | write `.ann` |
| Nested / overlapping | Weak toggle | Yes | Yes | Yes (native) |
| Curation + IAA | Thin | **Yes** | Multi-user | No |
| Setup / stateful footprint | **Lightest** | Heaviest (MariaDB + auth) | Medium (PG) | Python-2 pain |

- **Chosen: doccano** — lightest to stand up, keyboard-driven flat NER, clean JSONL import for pre-annotations; sufficient for **flat v1** (6 types). Dismissed: **Vi(M)** (single-user, no validation/IAA/token-aligned export) and **Prodigy** (commercial → fails open-source requirement).
- **Fallback: INCEpTION** — if model-in-the-loop active learning + multi-annotator curation/IAA + native nested spans become worth the heavier setup (adds a DB + auth → first stateful service; flag to `rharasim`).
- **Deployment**: standalone `docker-compose` campaign (all-in-one doccano image, host port 8001); converters live in `atrium-nlp-enrich`, nothing added to the runtime pipeline.

## 🏷️ `archaeo` types + output format
Six flat types `ARTEFACT · PERIOD · LOCATION · CONTEXT · MATERIAL · SPECIES` (hotkeys a/p/l/c/m/s). Export target = NameTag 3 IOB2: UTF-8, two tab-separated columns `token⇥label`, blank line between sentences, `-DOCSTART-→O`, `|`-joined labels for overlaps (`bronze → B-MATERIAL|B-ARTEFACT`) — the format `api_util/call_nametag.py::_get_ne_suffix` already parses.

## 📦 What landed (`annotation/`)
- `docker-compose.yml` + `.env.example` — standalone doccano (port 8001).
- `archaeo_labels.json` — 6-type label set, importable on the Labels page.
- `GUIDELINES.md` — per-type boundary rules (from #7 / ArchaeoBERT).
- `conllu_to_doccano.py` — CoNLL-U **or** IOB2 TSV → doccano import JSONL, optional pre-annotations (`NER=` MISC field or `call_nametag.py` TSV).
- `doccano_to_iob2.py` — doccano export JSONL → NameTag IOB2.
- `README.md` — end-to-end runbook.

Converters are stdlib-only; one doccano example = one document (sentence breaks = newlines, doc breaks = `-DOCSTART-`), which keeps the round-trip **token-aligned** (verified tag-exact on sample data; overlap → pipe verified).
