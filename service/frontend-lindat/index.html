ATRIUM NLP Document Enrichment

This service provides structural mapping, morphological tagging, syntactic parsing, and named entity recognition for archival documents, outputting TEITOK XML.

API usage 📡

This page is a thin client over the REST API. The same calls from the command line:

curl -X POST "http://localhost:8000/enrich" \
  -F "file=@lines.txt" -F "kw_method=keybert" -F "num_keywords=20"

curl -X POST "http://localhost:8000/enrich_text" \
  -H "Content-Type: application/json" \
  -d '{"lines": ["Výzkumná zpráva o nálezu."], "kw_method": "yake"}'
