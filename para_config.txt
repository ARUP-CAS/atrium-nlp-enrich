#     the project-wide floor for this repo — every core run is non-commercial
#     AND share-alike.
#   * KER (legacy lemma-frequency keyword extraction) is stdlib-only; it adds
#     no third-party license, so the repo MIT base applies for KER-only runs.
#   * YAKE is AGPL-3.0 (LIAAD/yake PyPI package); KeyBERT is MIT and pulls in
#     sentence-transformers (Apache-2.0). These are conditional: they only
#     constrain the optional keyword-extraction step that actually loads them.
#   * flexiconv (UFAL, optional; api_flexiconv.sh) declares GPL-3.0-or-later in its
#     pyproject.toml (checked at the pinned v0.3.10; the repo has no LICENSE file).
#     Conditional: it only constrains runs that actually convert documents with it.
